# 历史最好方案，不是正式版单轮成绩

这些是真实保存的自写 solver 最好方案，来自 26 次、多版本、多种子实验。
`summary.csv` 保留来源实验、种子、预算和旧源码 SHA-256；`audit_summary.json` 是原全量审计记录。
单 case `.json` 是依据该记录重建的成本/证书指标，已显式标注 provenance，不是新运行日志。

旧求解源码与完整探索目录已移到仓库外备份，不再作为公开仓库中的活动实现。
这些方案与证书可用当前 verify.py 独立核查，但不能据此宣称当前源码单次运行复现历史搜索轨迹。
正式版实测请看 `../release-20260917/`。
